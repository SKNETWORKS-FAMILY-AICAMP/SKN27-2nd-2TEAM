# 📊 고객 이탈 예측 기반 시뮬레이션 시스템 기획서 (초안)

## 1. 프로젝트 개요

본 프로젝트는 공개 데이터셋을 기반으로 고객 이탈(Churn) 예측 모델을 학습하고,
이를 활용하여 **고객 관리 전략을 가상 시나리오 형태로 시뮬레이션하는 시스템**을 구축하는 것을 목표로 한다.

단순한 예측 모델 구현을 넘어서,
**운영 관점에서 활용 가능한 분석 도구 형태의 인터페이스 제공**을 지향한다.

---

## 2. 주요 목표

* 고객 이탈 예측 모델 구축 및 성능 검증
* 고객 데이터를 기반으로 한 **현재 상태 분석 (Dashboard)**
* 특정 조건(정책/개입)에 따른 **이탈 위험도 변화 시뮬레이션**
* 데이터 분석 결과를 **서비스 형태 UI로 제공**

---

## 3. 데이터셋 관련 정책

* 사용 데이터셋: Kaggle Netflix User Watching Behavior Dataset (rhythmghai)
* 현재는 일반적인 넷플릭스 구독 모델을 가정하여 변수를 설계했으며, 실제 데이터셋 분석 후 상세 컬럼 및 모델 피처를 확정한다.
* 데이터 구조가 변경되더라도 대응 가능하도록 **유연한 설계 유지**

### 데이터 사용 원칙

* 전체 고객 데이터를 그대로 사용 (활성/비활성 포함)
* 단, 아래 조건의 데이터는 제외:

  * 비현실적 값
  * 데이터 누수 가능성이 있는 컬럼
  * 시뮬레이션에 부적합한 컬럼

---

## 4. 시스템 전체 구조

### 페이지 구성

#### ① 홈 (Dashboard)

* KPI 카드 4개
* 그래프 3개 (Dropdown 선택 방식)

#### ② 모델 & 데이터 설명

* 데이터셋 설명
* Feature 설명
* 모델 구조 및 성능

#### ③ 고객 시뮬레이션 (핵심 기능)

* 고객군 선택
* 정책 파라미터 설정
* 시뮬레이션 결과 비교

---

## 5. Dashboard 구성

### KPI 카드 (예시)

* 전체 고객 수
* 평균 churn probability
* 고위험 고객 수
* 베이직/스탠다드/프리미엄 요금제 비율

---

### 그래프 (Dropdown 선택)

사용자가 드롭다운에서 원하는 분석 관점을 선택하여 대시보드 그래프를 변경할 수 있습니다.

* **churn probability 분포**: 전체 고객의 이탈 확률이 어떻게 분포되어 있는지 보여주는 히스토그램. (예: 이탈 위험군이 전체의 몇 %를 차지하는지, 확률값이 특정 구간에 얼마나 밀집해 있는지 파악)
* **주요 feature별 이탈률**: 요금제, 월 시청 시간, 접속 기기 등 특정 변수의 값에 따라 이탈률이 어떻게 달라지는지 분석. (예: 베이직 요금제 사용자의 이탈률이 프리미엄보다 높은지 등 이탈의 주요 원인 파악)
* **고객 세그먼트별 비교**: 특정 속성으로 묶은 고객 그룹 간의 이탈 위험도 및 특성을 비교. (예: 20대 베이직 요금제 이용자 vs 40대 프리미엄 요금제 이용자의 평균 이탈 확률 비교)

---

## 6. 고객 시뮬레이션 기능 설계

본 시스템의 핵심 기능으로,
**고객군 단위 정책 시뮬레이션**을 수행한다.

---

## 6.1 전체 흐름

1. 고객군 선택 (Dropdown)
2. 시뮬레이션 파라미터 입력
3. 서버에서 해당 고객 데이터 조회
4. 원본 / 시뮬레이션 데이터 분리
5. 동일 모델로 재예측
6. 결과 비교 및 시각화

---

## 6.2 고객군 선택 방식

### 특징

* 사전 정의된 세그먼트 기반
* SQL 직접 입력 방식은 사용하지 않음

### 예시

* 최근 시청 시간 급감 고객
* 자동결제 미사용 고객
* 베이직 요금제 이용자 중 이탈 위험 상위 고객
* 장기 가입자 중 이탈 위험 상위 고객

---

## 6.3 시뮬레이션 파라미터

### 목적

* "정책 적용 시 어떤 변화가 발생하는가"를 분석

### 입력 방식

* Toggle / Slider / Selectbox

### 예시

* auto_renew (자동결제): ON/OFF
* subscription_plan (요금제): Basic -> Standard 등 변경
* monthly_revenue (월 결제액): 할인 적용 (-10%)

---

## 6.4 데이터 처리 구조

### 단계

```plaintext
고객군 데이터 조회
        ↓
DataFrame 생성
        ↓
original_df / simulated_df 분리
        ↓
simulated_df에 파라미터 적용
        ↓
동일 전처리 적용
        ↓
모델 예측 수행
        ↓
결과 비교
```

---

## 6.5 핵심 구현 로직 (개념)

```python
segment_df = fetch_segment()

original_df = segment_df.copy()
sim_df = segment_df.copy()

sim_df = apply_changes(sim_df, params)

X_original = preprocess(original_df)
X_sim = preprocess(sim_df)

pred_original = model.predict_proba(X_original)
pred_sim = model.predict_proba(X_sim)
```

## 7. 결과 시각화 설계

### 7.1 상단 요약

시뮬레이션 실행 후, 사용자가 어떤 조건으로 분석을 요청했는지 헷갈리지 않도록 결과 화면 최상단에 설정값들을 요약해서 보여주는 UI 영역입니다.

* **선택 고객군** (예: 최근 시청 시간 급감 고객)
* **분석 대상 고객 수** (예: 1,245명)
* **적용된 정책 요약** (예: 베이직 -> 스탠다드 요금제 변경, 월 결제액 10% 할인)

---

### 7.2 KPI 비교

* 평균 churn probability (Before / After)
* 고위험 고객 수 변화
* 고위험 비율 변화
* 예상 개선 고객 수

---

### 7.3 그래프

#### 1. 분포 비교 (Histogram / Density Plot)

* **Before vs After Churn 분포**: 동일한 그래프 내에서 정책 적용 전(Before)과 후(After)의 이탈 확률 분포를 겹쳐서(Overlaid) 보여줍니다. 이를 통해 정책 적용 후 이탈 위험이 전체적으로 얼마나 낮아졌는지 시각적으로 직관적인 비교가 가능합니다.
