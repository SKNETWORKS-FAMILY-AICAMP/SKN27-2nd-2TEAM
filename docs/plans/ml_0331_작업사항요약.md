## 변경 상세
### 1) user_id 중복 통합 및 병합 기준 정리
- 이벤트성 테이블(watch/rec/search/review)을 `user_id` 단위로 선집계 후 users와 left merge
- 집계 기준:
  - 날짜/시간 컬럼: `max`(최근값)
  - 수치형: 기본 `mean`, 이벤트량 성격(`count`, `duration`, `votes`, `results`, `sessions`)은 `sum`
  - 범주형: 최빈값(mode)
- 병합 결과 행 수가 users 행 수와 다르면 예외를 발생시켜 정합성 보장

### 2) Train/Test 분할 로직 단순화
- `split_data()` 입력을 단일 DataFrame으로 단순화
- 반환 구조에서 `ori_te` 제거
- `test_size=0.2`, `stratify=y` 고정 적용

### 3) 전처리 함수 시그니처 정리
- `drop_columns(train, test, ori_te)` -> `drop_columns(train, test)`
- `fill_missing_values(train, test, ori_te)` -> `fill_missing_values(train, test)`
- 내부 반복 루프에서도 `ori_te` 관련 처리 제거

### 4) 메인 학습 파이프라인 정렬
- 신규 메인 엔트리 `models/model_netflix.py` 추가
- 흐름: 로드 -> 타겟 생성 -> user 단위 병합 -> split -> cleaning -> encoding -> train/eval -> 저장/시각화
- 각 단계에 목적 중심 주석을 추가해 유지보수 가독성 보강
- 기존 `models/model_netflex.py`는 호환용 포워딩 엔트리로 유지

### 5) 실행 결과 통계 함수 정합화
- `save_results()`에서 `zero_division=0` 옵션을 적용해 극단 예측 시에도 안전하게 지표 계산
- `summarize_results()`에 빈 결과 가드 추가
- `save_submission()`은 내부 split 결과를 바로 저장하도록 정리

### 6) 네이밍 오타 정리 (Netflex -> Netflix)
- 모델 저장 경로를 `model_netflix.pkl`로 통일
- 레거시 파일(`model_Netflex.pkl`, `model_netflex.pkl`)은 저장 시 정리 로직 유지
- 보조 스크립트에서도 모델 로드명을 `model_netflix.pkl`로 통일

### 7) 중간 산출물(`netflix_users.csv`) 생성 및 결측치 전략 기반 추가
- `load_data.get_args()`에 `netflix_users_csv` 경로를 추가하여 파이프라인에서 공통 사용
- `model_netflix.py`에서 병합 직후 데이터(`users` 기준 1행)를 `models/data/netflix_users.csv`로 저장
- 저장 직후 `is_churned` 존재 여부/행수 로그를 출력해 중간 테이블 정합성 확인
- `cleaning.py`에 `profile_missing_values()`를 추가해 컬럼별 결측 프로파일 생성
  - 출력: 컬럼명, 결측 개수, 결측 비율, dtype, 고유값 수, 전략 후보
  - 결측 구간 요약: `0%`, `(0%,5%)`, `[5%,30%]`, `>30%`
- 전략 후보(`strategy_candidate`) 자동 라벨링 기준:
  - 수치형: `median_impute`, `group_median_or_median`, `zero_or_group_median`
  - 범주형: `mode_impute`, `mode_or_unknown`, `unknown_label_or_drop`
  - 결측 과다(>40%): `drop_candidate(high_missing)`

### 8) `netflix_users.csv` 컬럼별 결측치 처리 확정안 반영
- 실측 기준(10,300 rows / 79 cols)으로 결측 컬럼을 구간화하고 `fill_missing_values()`를 컬럼군 기반으로 확장
- 사용자 핵심(기존 유지):
  - `age` -> 중앙값
  - `gender` -> 최빈값
  - `monthly_spend`, `household_size` -> 연령대 중앙값 후 전체 중앙값 fallback
- watch 그룹:
  - `watch_user_rating`, `watch_number_of_episodes`, `watch_box_office_revenue`, `watch_production_budget` -> train 중앙값
  - `watch_number_of_seasons` -> `watch_content_type` 그룹 중앙값 후 전체 중앙값
  - `watch_genre_secondary` -> 최빈값(없으면 `Unknown`)
- rec 그룹:
  - 수치형(`rec_recommendation_score`, `rec_was_clicked`, `rec_position_in_list`, `rec_event_count`) -> 중앙값
  - 범주형/ID/시간(`rec_*` object 컬럼) -> `Unknown`
- search 그룹:
  - `search_results_returned`, `search_search_duration_seconds` -> 중앙값
  - `search_had_typo`, `search_used_filters`, `search_event_count` -> 0
  - `search_search_date`, `search_search_id`, `search_search_query`, `search_device_type`, `search_location_country` -> `Unknown`
  - `search_clicked_result_position` -> `-1` (클릭 없음 의미 구분)
- review 그룹:
  - 수치형(`review_rating`, `review_sentiment_score`, `review_is_verified_watch`, `review_helpful_votes`, `review_total_votes`, `review_event_count`) -> 0
  - 범주형/텍스트/ID/시간(`review_sentiment`, `review_review_text`, `review_review_id`, `review_movie_id`, `review_device_type`, `review_review_date`) -> `NoReview`
- `model_netflix.py`에 결측 처리 전/후 총량 및 핵심 컬럼 결측 로그를 추가해 적용 결과를 즉시 확인 가능하게 함

### 9) 날짜 분해 + 혼합 인코딩 + 사전 검증 게이트 반영
- 날짜 컬럼(`*_date`, `*_at`)을 인코딩 직전에 자동 탐지해 `year/month/day`로 분해하고 원본 날짜 컬럼 제거
- ID성 컬럼(`user_id`, `email`, `*_id`)은 인코딩 대상에서 제거
- 인코더를 `encoder_type` 인자로 선택 가능하도록 확장
  - `hybrid`(기본): 유니크 `<=5`는 OneHot, `>5`는 Label(Ordinal)
  - `onehot`: 범주형 전체 OneHot
  - `label`: 범주형 전체 Label(Ordinal)
- `model_netflix.py` 실행 시 `--encoder-type` CLI 인자로 모드 선택 가능
- 인코딩 직전 `fail-fast` 검증 게이트 추가:
  - train/test 컬럼 불일치
  - 날짜 원본 컬럼 잔존
  - ID성 컬럼 잔존
  - 결측치 잔존
  - 위 조건 중 하나라도 실패하면 `ValueError`로 즉시 중단하고 원인 출력
- 결측치 처리 로직에서 날짜 컬럼(`rec_recommendation_date`, `search_search_date`, `review_review_date`)은 파싱 가능한 기준일(`1970-01-01`)로 보정
- 인코딩 직전에 숫자형이 아닌 모든 공통 컬럼을 `category` dtype으로 강제 변환하는 단계 추가
- 사전 검증 게이트에 `object dtype` 잔존 체크를 추가하여, `category` 변환 누락 시 즉시 중단
