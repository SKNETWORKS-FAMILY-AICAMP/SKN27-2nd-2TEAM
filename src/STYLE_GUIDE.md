# 🎨 코드 작업 스타일 가이드 (Style Guide)

이 문서는 프로젝트 내에서 UI 화면을 개발하고 모듈화할 때 지켜야 하는 **표준 작업 방식과 코드 구조**를 정의합니다. 나중에 코드를 다시 수정하거나 새로운 페이지를 추가할 때, 이 가이드를 참고하여 일관된 퀄리티와 유지보수성을 확보합니다.

---

## 1. 디자인 모듈화 (CSS / HTML 주입)

Streamlit의 기본 레이아웃 제약을 극복하고 커스텀 디자인을 일관되게 적용하기 위해, 디자인 관련된 코드는 순수 파이썬 로직과 분리하여 관리합니다.

*   **위치:** `src/design/`
*   **분리 전략:** 
    *   앱 전체에 공통으로 적용될 스타일(폰트, 여백, 기본 색상)은 `common.py`에 작성합니다.
    *   지표 카드, 차트, 사이드바 등 특정 컴포넌트에 특화된 CSS는 `metrics.py`, `charts.py` 등 각각의 파일로 분리하여 함수(예: `get_metrics_css()`) 단위로 반환하게 작성합니다.
*   **테마 색상 (글로벌 딕셔너리 관리):**
    *   색상 토큰(예: Netflix Red `#FF4B4B`)은 하드코딩하지 않고, `src/design/common.py` 최상단에 선언된 **`COLORS` 딕셔너리**로 중앙 집중화하여 관리합니다.
*   **적용 방법:**
    *   생성된 전체 CSS 문자열은 `st.markdown(unsafe_allow_html=True)` 혹은 `st.html()`을 사용하여 앱의 `main.py` 실행 시점에 한 번에 주입합니다.

---

## 2. UI 텍스트 및 환경 설정 분리 (Config)

애플리케이션 화면에 직접 표출되는 '텍스트(문구)'와 '하드코딩 설정값'은 파이썬 소스 코드에서 완전히 분리합니다.

*   **위치:** `src/config/ui_config.json`
*   **목적:** 화면 제목, 폼 라벨명, 옵션 리스트, 설명글 등을 구조화된 JSON 포맷으로 보관합니다.
*   **활용 방법:**
    *   파이썬 로직에서는 `src/utils/data_loader.py`에 정의된 `load_ui_config()` 함수를 호출하여 파이썬 딕셔너리 형태로 텍스트 묶음을 불러옵니다.
    *   불러온 텍스트는 `f-string` 등의 포맷팅을 통해 HTML 템플릿 또는 Streamlit 네이티브 UI 함수에 매핑합니다.

---

## 3. 샘플 및 표시용 데이터 분리 (Data)

실제 데이터베이스나 머신러닝 파이프라인이 완벽히 연결되기 전, 대시보드 표출용으로 사용하는 샘플 데이터 및 기초 데이터의 관리 규칙입니다.

*   **위치:** `data/sample/` 디렉토리 내의 `.csv` 파일
*   **예시 파일:**
    *   `dashboard_metrics.csv` : 대시보드 상단 KPI 카드에 들어갈 통계치 데이터
    *   `simulator_sample.csv` : 이탈 시뮬레이터 폼 렌더링 시 사용할 기본 설정값(디폴트 파라미터)
    *   `chart_data.csv` : 시계열 차트 등을 그리기 위한 샘플 데이터
*   **활용 방법:**
    *   모든 데이터 로딩은 파이썬 내에서 파일 경로를 직접 열지 않고, **`src/utils/data_loader.py`** 에 정의된 전용 로드 함수(예: `load_metrics_data()`, `load_simulator_data()`)를 사용합니다.
    *   반드시 성능 최적화를 위해 `@st.cache_data` 데코레이터를 적용합니다.

---

## 4. 화면(Screen) 렌더링 패턴

페이지(Screen)를 구현하는 파일들은 로직 처리와 레이아웃 조립의 역할을 담당합니다.

*   **위치:** `src/screens/`
*   **작성 패턴:**
    1.  **페이지 렌더링 함수 정의:** `render_dashboard()`, `render_model()` 등 하나의 페이지를 렌더링하는 메인 진입점 함수를 작성합니다.
    2.  **공통 헤더(Header):** 모든 페이지 최상단에는 항상 `page-header`, `page-title`, `page-description` 클래스를 가진 HTML을 주입하여 페이지 제목과 설명을 통일감 있게 표출합니다.
    3.  **레이아웃 혼합 사용:** 
        *   표준화된 그리드나 입력 폼 등은 Streamlit의 내이티브 레이아웃(`st.columns`, `st.form`)을 사용합니다.
        *   디자인 자유도가 필요한 커스텀 UI(KPI 카드, 프로그레스 게이지 차트 등)는 파이썬에서 `f-string`으로 HTML 구조를 짠 뒤 `st.html()` 로 렌더링합니다.
        *   CSS 스타일 클래스 지정 시 `ui_config`에서 불러온 데이터나 `COLORS` 딕셔너리를 활용해 동적으로 색상 및 구조를 반영합니다.
